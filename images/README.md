# Outfit images

Drop 14 JPGs in this folder, named `{colour}-her.jpg` and `{colour}-him.jpg` (lowercase colour).
Portrait photos work best; they are cropped to a 4:5 frame (`object-fit: cover`). Any missing file
shows a styled placeholder instead, so the site works with none, some or all of them.
